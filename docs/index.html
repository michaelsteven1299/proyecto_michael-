Precisión del modelo: predicción vs. realidad

Cada día hábil el modelo predice el precio del día siguiente. Cuando ese día llega, se compara la predicción contra el precio real. Este historial crece automáticamente y nunca se edita retroactivamente.

Metodología y comparación de modelos (para quien quiera revisar el detalle técnico)

15 algoritmos evaluados con 6 ventanas temporales sucesivas (TimeSeriesSplit), midiendo la mejora de RMSE frente a la referencia de persistencia (asumir que el retorno de mañana es cero). El modelo en producción se reentrena todos los días con el histórico completo disponible.

Fuente: Yahoo Finance vía la librería yfinance (GLD, COP=X, DX-Y.NYB, ^VIX, CL=F, ^TNX). Modelo: Regresión Lineal, reentrenada diariamente sobre todo el histórico disponible.

Automatización: un workflow de GitHub Actions descarga los datos, reentrena el modelo y publica los resultados todos los días hábiles después del cierre de mercado — sin intervención manual. Ver el código en GitHub →

Este es un proyecto académico con fines educativos. Las predicciones y simuladores no constituyen asesoría financiera ni recomendación de inversión ni de compraventa de oro.
